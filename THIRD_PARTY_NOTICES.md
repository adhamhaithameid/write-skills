# Third-party notices

This collection derives from the projects below. Each entry states the license at the time of writing and how the project was used.

## MIT licensed

- mattpocock/skills (MIT). The agent-document reference and the three writing workflow stages (fragments, shape, beats) informed the agent mode of write-docs and the stages of write-longform. The vertical-slice ticket pattern informed write-jira. The text in this collection was rewritten and condensed. https://github.com/mattpocock/skills
- humanlayer/skills, the show-me skill by Dex Horthy (credited in that skill). Its PR template idea, summary plus evidence plus merge danger, informed write-pr. The text in this collection was rewritten. https://github.com/humanlayer/skills
- JuliusBrussee/caveman (MIT; the repository also ships an Apache-2.0 license file, and its plugin manifest declares MIT). The brief-voice rules in write-better and write-compact were written fresh for this collection. No text from that repository was copied. Named to credit the idea. https://github.com/JuliusBrussee/caveman
- Hakku/finnish-humanizer (MIT). Its pattern-catalog method was reviewed during design. No text from it appears here. https://github.com/Hakku/finnish-humanizer

## Origin unknown

- A layered technical-writing rule set was collected in the source workspace of this project, with no author and no license metadata. It was the starting point for the docs standard. Every file in this collection that draws on it was rewritten sentence by sentence for this release, and the worked example was replaced. If you hold rights to that rule set, open an issue and this collection will add credit or rewrite further.

## Standards and style guides

- ASD-STE100, Issue 9 principles. https://asd-ste100.org/ and https://en.wikipedia.org/wiki/Simplified_Technical_English. The STE rules in this collection are our own summary.
- Diataxis framework by Daniele Procida. https://diataxis.org/. The four mode names are used under the framework.
- Google developer documentation style guide. https://developers.google.com/style. The sentence rules in this collection are our own summary.
